# Campus Lost & Found Portal

A full-stack web application that helps students report lost and found items, search listings, and submit claims.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT

## Features
- Student registration and login
- Report lost and found items with image upload
- Search and filter items
- Sort items by date
- Submit and manage claims
- Student dashboard
- Admin dashboard
- Update item status
- Secure authentication

## Custom Feature
- Duplicate-item alert based on item title and category.

## Setup Instructions
1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Create a `.env` file using `.env.example`.
5. Configure MongoDB connection details.
6. Run `npm start`.
7. Open `http://localhost:5000` in your browser.
